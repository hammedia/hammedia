확인된 작업 왕복 · 어디까지 실제인가요?
실제 전달·반환 확인 / 현장 시연 시간 미검증

부탁은 건너갔고, 결과는 돌아왔습니다.

요청 정리 → 기존 작업장에서 제작 → 반환 결과 확인

가상 자전거 수리점 문안을 실제로 맡겨 반환받은 경로입니다. 다른 계정의 Dot끼리 직접 자동 통신한 사례는 아닙니다. 위 순서는 이미 확인한 경로의 설명이며, 이 페이지에서 새 작업이 실행되고 있다는 표시는 아닙니다.

아래 사전 예시는 학습을 위해 새로 쓴 문안입니다. 실제 반환 원문을 그대로 복제한 것이 아닙니다. 현장 6분 시연과 25분 소리내어 리허설은 별도 확인이 필요합니다.

시연이 2분 넘게 지연된다면 · 사전 예시 열기
새로 작성한 수업용 예시 · 실제 반환 원문 아님

가상 자전거 수리점의 방문 전 관찰 안내

고객: 자전거 상태를 설명하기 어려운 방문자
문제: 어디가 이상한지 말하기 어려워 상담이 길어짐
건넬 결과: 방문 전에 눈으로 살펴볼 3가지 안내문 한 장
범위: 타이어가 꺼져 보이는지, 소리가 나는 위치, 증상이 시작된 때를 기록. 수리 진단·안전 판정은 하지 않음
확인 질문: “이 안내를 읽고 어떤 장면을 기록하면 될지 알겠나요?”

현장 실행은 강사의 기존 작업장에서 별도로 보여줍니다. 이 예시는 AI를 지금 호출한 결과가 아닙니다.
