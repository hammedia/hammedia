1기 추가 안내 · MUSE

Muse가 처음이라면,
여기서 시작하세요.

Muse(뮤즈)는 Meta의 AI입니다.
대화로 부탁하면 소개글 정리, 생활 자료 비교,
문서 초안 만들기 등을 도와줍니다.

이번에는 개인정보 없는 짧은 소개글 하나를 만들어봅니다.
AI가 쓴 내용을 내 말로 고치고, 저장한 글을 다시 열어보세요.

이미 Muse를 쓰고 있다면 첫 실습으로 바로 가세요.

시작하기 · 네 단계

설치 없이 웹으로 시작하세요.

  1. 무료 조건을 먼저 확인하세요.

    Muse는 사용량 한도 안에서 무료로 쓸 수 있습니다. 한도를 다 쓰면 갱신을 기다리거나 유료 이용을 선택할 수 있습니다. 이번 글 실습을 위해 결제를 서두를 필요는 없습니다.

    이용 대상은 18세 이상이며, 국가에서 정한 기준이 더 높으면 그 기준을 따릅니다. 사용 가능 여부와 무료 한도는 본인 계정 화면에서 확인하세요. 공식 이용약관 ↗ · 무료 사용 안내 ↗

  2. 공식 웹에서 로그인하거나 계정을 만드세요.

    공식 Muse 웹 열기 ↗

    첫 화면에서 ‘로그인 또는 계정 만들기’를 누릅니다. 이어서 ‘휴대폰 번호 또는 이메일 주소 (필수)’에 본인이 사용할 정보를 직접 입력하고 ‘계속’을 누르세요. 입력하기 전에는 ‘계속’ 버튼이 비활성 상태입니다.

    이후 인증과 계정 안내는 실제 화면을 따라 진행하세요. 이미 Meta 계정이 있다면 그 계정으로 로그인합니다. 가입 중 유료 선택이 나오면 무료로 이용할 수 있는 조건부터 확인하세요.

    2026년 10월 7일 한국어 공개 화면에서 위 입구까지 확인했습니다. 한국 신규 계정의 가입 완료와 앱 설치는 직접 확인하지 않았습니다. 공식 첫 사용 도움말 ↗

  3. 지금 쓰는 기기의 웹으로 시작하세요.

    PC나 휴대폰의 인터넷 브라우저에서 Muse를 열어 이번 글 실습을 시작합니다. 앱 설치는 선택입니다. 앱을 쓰고 싶다면 공식 다운로드 안내에서 기기를 선택하세요.

    앱 연결이나 전체 디스크 권한, 고객 자료 업로드는 이 실습의 준비물이 아닙니다.

    iPhone·Android·Mac 설치 도움말 ↓ · 이용이 안 되면 평소 쓰는 AI에서 해보세요 →

  4. 소개글 하나를 만들고 다시 열어보세요.

    아래에서 할 일을 하나 고른 뒤 요청문 복사 → Muse 대화에 전송 → 한 번 수정 → 저장·다시 열기를 따라갑니다. 처음에는 실제 개인정보 대신 가상 책방 예시를 써도 좋습니다.

    첫 실습: 내가 해볼 일 고르기 ↓

첫 실습 01 · 내 일 선택 → 요청

무엇부터 해볼까요?

하나를 고르면 요청문이 열립니다. 빈칸을 내 내용으로 바꾸고 복사해 Muse의 대화 입력창(Chat)에 붙여넣고 전송하세요.

Muse Chat에서 보내기 ↗

확인할 것: 실제 제공하지 않는 서비스나 근거 없는 표현이 들어가지 않았나요?

여기 적은 내용은 서버로 보내지 않습니다. 새로고침하거나 닫기 전에 필요한 문장을 복사해두세요. Muse에 직접 보낸 내용에는 Muse의 데이터 처리 정책이 적용됩니다.

빈칸이 막막하다면: 직접 해본 ‘햇살책방’ 예시

실제 사업장이 아닌 교육용 가상 예제입니다. 아래 요청 → 수정 → 라이브러리 저장 → 다시 열기를 2026년 10월 5일 기존 무료 웹 계정에서 확인했습니다. 결과 문장은 실행할 때마다 달라질 수 있습니다.

처음 받은 답

햇살책방은 동네의 작은 독립서점입니다. 매주 토요일에는 독서모임이 열려 이웃들이 책 이야기를 나눕니다. 처음 오신 분도 편히 쉬어갈 수 있는 공간입니다.

첫 문장을 지정해 바꾸고, 전체를 다정하게 다듬도록 요청했습니다.

고친 뒤 실제로 저장한 답

책과 함께 잠깐 쉬어가는 동네 독립서점, 햇살책방입니다. 매주 토요일에는 독서모임이 열려, 이웃과 함께 따뜻한 책 이야기를 나눌 수 있습니다. 처음 오시는 분도 부담 없이 들러 편히 쉬어 가실 수 있는 아늑한 공간입니다.

첫 실습 02 · 사실 확인 → 한 번 수정

내가 아는 사실과 맞나요?

AI가 새로 붙인 위치·가격·날짜는 없는지, 읽을 사람에게 말투와 길이가 맞는지 확인하세요. 고칠 곳 하나를 같은 대화에서 이어서 부탁합니다.

이미 쓸 만하다면 억지로 고치지 않아도 됩니다. 그대로 쓸 이유 한 가지를 남겨보세요.

첫 실습 03 · 원문과 결과 보존 → 다시 활용

저장했다면, 다시 열어보세요.

같은 대화에서 “수정한 결과를 [찾기 쉬운 제목]으로 라이브러리에 저장해주세요”라고 부탁해보세요. 가상 예제라면 실제 사업장이 아니라는 표시도 함께 남깁니다.

아래는 PC 웹에서 확인한 순서입니다. 기기·계정에 따라 메뉴가 다르면 저장한 제목으로 문서를 찾아 다시 여세요.

  1. 왼쪽 라이브러리를 엽니다.
  2. 모든 아티팩트에서 저장한 제목의 카드를 누릅니다.
  3. 문서 편집 창에서 고친 문장이 실제로 남았는지 확인합니다.

확인 사례: ‘햇살책방 소개 — 교육용 가상 예제.md’를 다시 열어 수정한 세 문장과 “교육용 가상 예제입니다. 실제 사업장이 아닙니다.” 표시를 확인했습니다.

처음 부탁한 말도 함께 남겨두세요.

최종 답만 있으면 다음에 어떻게 만들었는지 잊기 쉽습니다. 메모에 아래 네 줄을 남기거나, 기존 1기 활동지에 옮겨 글 파일로 저장하세요.

  • 처음 부탁한 말
  • 내가 고친 점
  • 실제로 쓸 최종 결과
  • 다음에 다시 쓸 상황

필요할 때 펼쳐보세요

설치와 막힘 도움말

iPhone·Android·Mac 앱을 쓰고 싶어요

이번 실습은 웹 시작 순서를 먼저 따라가세요. 앱이 필요하면 공식 다운로드 안내에서 기기를 선택합니다.

  • iPhone: App Store 안내를 확인하세요.
  • Android: Google Play 안내를 확인하세요.
  • Mac: 공식 다운로드 안내의 Mac 버튼을 이용하세요.

본인 기기의 스토어에서 설치 가능 여부와 필요한 OS를 확인하세요. 한국 스토어 설치는 직접 시험하지 않았습니다.

Mac 권한은 어디까지 허용하나요?

이번 웹 글 실습은 새 권한 없이 확인했습니다. 전체 디스크 접근이나 앱 조작 권한을 한꺼번에 허용할 필요는 없습니다. 앱에서 권한을 물으면 하려는 일에 필요한 범위를 읽고 선택하세요.

공식 Mac 권한 안내에는 Off, Read only, Read and interact 등의 접근 수준이 설명되어 있습니다.

무료 한도나 이용 가능 여부에서 막혔어요

한도를 다 썼다면 화면의 갱신 안내를 확인하고 기다려도 됩니다. 유료 이용은 선택이며, 가입이나 첫 실습을 위해 무조건 결제하지 마세요.

화면이 안내와 다르거나 이용이 안 되면 평소 쓰는 AI에서 이어가세요. 요청문과 결과를 함께 보관하면 같은 실습을 할 수 있습니다.

복사·사진·파일 저장이 어려워요
  • 복사 버튼이 안 되면 요청문을 직접 선택해 기기의 복사 메뉴를 쓰세요.
  • 사진은 올리지 않아도 됩니다. 보이는 내용을 글로 설명하세요.
  • 답이 너무 길면 “두 문장으로 먼저 보여주세요”라고 요청하세요.
  • 활동지 다운로드가 안 되면 카카오톡 안의 화면 대신 휴대폰 인터넷 브라우저로 열어보세요.
  • 라이브러리 저장이 안 되면 요청문과 결과를 메모나 활동지에 남긴 뒤 파일을 다시 열어 확인하세요.

도움을 구할 때는 아래 네 줄을 적어보세요. 막막하면 첫 줄만 적어도 됩니다. 개인정보는 지우거나 가린 뒤 공유하세요.

내 자료는 필요한 만큼만

공개 가능한 내용이나 가상 자료로 시작하세요. 고객 개인정보, 계약 자료, 계정 비밀번호는 실습에 넣지 마세요. Muse에 입력하거나 올린 자료에는 해당 서비스의 데이터 처리 정책이 적용됩니다.

Meta는 연결 앱·접근 범위 변경과 연결 해제, 상호작용의 AI 학습 사용 거부를 안내합니다. 실제 설정은 본인 화면에서 확인하세요. Muse가 대화를 기억하거나 이후 작업의 배경으로 활용할 수 있다는 점도 생각하세요.

다른 사람의 사진·작업물은 사용 권한을 확인하고, 외부에 보내거나 공개하기 전 내용과 범위를 다시 확인합니다. Meta 개인정보·접근권한 설명 ↗

직접 확인한 범위

사용 중인 무료 웹 계정에서 가상 책방 소개 작성 → 한 번 수정 → 라이브러리 저장 → 문서 다시 열기까지 확인했습니다. 이 과정에 새 설치·추가 권한·결제는 없었습니다.

공개 홈페이지를 읽고 한국어로 답하는 과정도 확인했습니다. 모든 기기에서의 설치, 한국 신규 계정 가입, 모든 수정·저장 기능을 보장하는 확인은 아닙니다.

공식 안내와 실제 화면은 바뀔 수 있습니다. 현재 조건은 아래 공식 페이지와 본인 계정 화면을 확인하세요.
