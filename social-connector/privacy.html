현재는 개발·준비 단계입니다. 외부 고객 계정은 아직 연결하지 않았고 실제 고객 데이터나 접근 토큰을 수집·저장하지 않았습니다.

1. 현재 운영 상태

HAM MEDIA Social Connector는 HAM MEDIA가 관리하는 테스트 계정으로 검증할 예정입니다. 외부 고객 계정 연결, 실제 고객 데이터 수집, 게시·댓글 관리와 API 호출은 아직 시작하지 않았습니다.

2. 서비스 제공 시 다룰 수 있는 정보

사용자가 Meta 로그인과 권한 화면에서 직접 승인한 범위 안에서 다음 정보를 다룰 수 있습니다.

  • 계정 식별자와 공개 프로필 기본정보
  • 연결한 Threads·Instagram·Facebook 계정 또는 페이지 식별정보
  • 사용자가 승인한 접근 권한과 접근 토큰
  • 게시물, 미디어, 답글, 댓글과 멘션
  • 게시물과 계정의 인사이트·성과정보
  • 연결·게시·오류 확인에 필요한 최소 운영기록
  • 사용자가 문의할 때 직접 제공한 연락정보와 문의 내용

비밀번호·일회용 인증번호·복구코드는 요청하거나 저장하지 않습니다.

3. 이용 목적

  • 사용자가 승인한 소셜 계정을 연결하기 위해
  • 콘텐츠 초안 확인, 예약·게시와 게시 결과 확인을 지원하기 위해
  • 답글·댓글·멘션 확인과 사용자가 승인한 대응을 지원하기 위해
  • 인사이트와 성과를 정리해 사용자에게 보고하기 위해
  • 연결 오류, 보안 문제와 서비스 품질을 확인하기 위해
  • 문의와 데이터 삭제 요청에 답하기 위해

4. 외부 서비스 이용과 제3자 제공

서비스는 사용자가 선택한 기능을 제공하기 위해 Meta Platforms의 공식 로그인과 API를 사용할 수 있습니다. 사용자 정보를 판매하지 않으며, 사용자가 승인하지 않은 계정에 접근하지 않습니다. 다른 외부 처리업체를 도입할 경우 실제 수집 전에 이 문서를 갱신하고 필요한 안내를 제공합니다.

5. 보관과 보호

접근 토큰과 인증정보가 발급되는 경우 공개 홈페이지·공개 저장소·일반 업무문서에 기록하지 않고 접근이 제한된 별도 보관 위치에서 관리합니다. 정보는 기능 제공과 삭제 요청 처리에 필요한 기간 동안만 보관하며, 연결 해제·삭제 요청 또는 이용 목적 종료 뒤 불필요한 정보는 삭제합니다. 법령상 별도 보관 의무가 있는 정보는 해당 범위에서만 분리 보관할 수 있습니다.

6. 연결 해제와 삭제 요청

사용자는 Meta 계정 설정에서 앱 연결을 해제할 수 있고 HAM MEDIA에 서비스 데이터 삭제를 요청할 수 있습니다.
