1. 목적과 적용

이 약관은 HAM MEDIA가 제공하는 Social Connector의 계정 연결, 프로필·콘텐츠·성과정보 확인, 콘텐츠 초안 업로드와 관련 기능의 이용 조건을 설명합니다. 사용자는 서비스를 이용하기 전에 이 약관과 개인정보처리방침을 확인해야 합니다.

2. 계정 연결과 권한 승인

사용자는 본인이 관리하거나 연결 권한을 가진 TikTok·Instagram·Facebook·Threads 계정만 연결할 수 있습니다. 계정 연결과 API 권한은 각 외부 서비스의 공식 로그인·권한 화면에서 사용자가 직접 승인하며, 승인하지 않은 권한은 사용할 수 없습니다.

비밀번호·일회용 인증번호·복구코드는 HAM MEDIA에 전달하지 마세요.

3. 제공하는 기능

  • 연결한 계정의 공개 프로필과 사용자가 승인한 계정정보 확인
  • 사용자가 승인한 콘텐츠·댓글·성과정보 확인과 정리
  • 콘텐츠 초안 검토와 사용자 승인 뒤 업로드 또는 게시 지원
  • 연결 오류 확인, 연결 해제와 데이터 삭제 요청 지원

실제 제공 기능은 외부 플랫폼의 승인 범위, API 정책, 계정 상태와 개발 단계에 따라 달라질 수 있습니다.

4. 사용자 확인과 게시 책임

사용자는 게시 전 콘텐츠, 공개 범위, 설명문, 해시태그와 대상 계정을 직접 확인해야 합니다. HAM MEDIA는 사용자의 명시적 승인 없이 연결 계정에 콘텐츠를 몰래 게시하지 않습니다. 사용자는 게시할 자료에 필요한 저작권·초상권·상표권과 기타 이용 권한을 확보해야 합니다.

5. 금지되는 이용

  • 타인의 계정이나 권한 없는 계정을 연결하는 행위
  • 스팸, 사기, 불법 콘텐츠, 권리 침해 콘텐츠를 배포하는 행위
  • 외부 플랫폼의 정책·기술적 제한·보안 절차를 우회하는 행위
  • 서비스나 API에 과도한 요청을 보내거나 안전한 운영을 방해하는 행위
  • 접근 토큰·앱 비밀키·인증정보를 다른 사람에게 노출하는 행위

6. 외부 플랫폼

Social Connector는 TikTok과 Meta의 공식 로그인·API를 이용할 수 있습니다. 각 플랫폼의 장애, 심사, 권한 회수, 기능 변경, 사용 제한과 정책 적용은 해당 플랫폼이 정합니다. 사용자는 연결한 외부 플랫폼의 약관과 정책도 따라야 합니다.

7. 서비스 변경과 중단

보안 문제, 외부 API 변경, 점검, 법령 또는 플랫폼 정책 준수를 위해 기능을 변경하거나 일시 중단할 수 있습니다. 사용자 데이터 처리에 중요한 변경이 있으면 적용 전에 공개 문서를 갱신합니다.

8. 연결 해제와 이용 종료

사용자는 언제든 외부 플랫폼의 앱 권한 설정 또는 Social Connector의 연결 해제 기능을 통해 연결을 종료할 수 있습니다. 서비스가 보관한 데이터의 삭제는 사용자 데이터 삭제 안내에 따라 요청할 수 있습니다.

9. 책임의 범위

HAM MEDIA는 승인된 범위에서 서비스를 안전하게 운영하도록 노력합니다. 다만 외부 플랫폼의 장애·정책 변경, 사용자의 잘못된 계정 선택·권한 부여·게시 승인, 사용자가 제공한 자료의 권리 문제처럼 HAM MEDIA가 통제할 수 없는 사유로 발생한 결과까지 보장하지는 않습니다. 관련 법령이 달리 정하는 경우에는 그 법령을 따릅니다.
