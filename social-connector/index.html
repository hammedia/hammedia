User-authorized social workflow

Social Connector

A HAM MEDIA production tool that lets an authorized user review their TikTok account and videos, choose one video, and send it to TikTok as a draft for final review in the TikTok app.

OperatorHAM MEDIA Service stageControlled production review Available toHAM MEDIA-authorized accounts Contacthammedia002@gmail.com
No automatic public posting. The user approves access on TikTok, chooses the source video, and completes the final publishing decision inside TikTok.

What the service does

Social Connector supports HAM MEDIA's short-form production workflow. It brings account and video information into one review screen so the account owner and production operator can confirm the correct source before creating a TikTok draft.

Account confirmationShows the connected account's public profile and account statistics.
Video selectionLists videos available to the authorized account so the user can select the intended source.
Draft transferSends the selected video to TikTok as a draft. It does not publish the video publicly.
Disconnect and deleteLets the user revoke access and request deletion of service-side connection data.

Complete user flow

  1. Open Social Connector.The user reads this service description and starts the connection from the button below.
  2. Authorize on TikTok.TikTok displays the requested permissions. The user may approve or cancel.
  3. Review the account.The service shows the connected profile, statistics, and recent videos for confirmation.
  4. Select a video.The user chooses the intended source and confirms the draft transfer.
  5. Finish in TikTok.The video arrives as a TikTok draft. The user reviews it and decides whether to publish.

Continue with TikTok

During platform review, access is limited to accounts authorized by HAM MEDIA. External customer accounts are not connected during this stage.

Permissions and their purpose

PermissionHow Social Connector uses it
user.info.basicConfirms the connected TikTok account.
user.info.profileDisplays the user's authorized profile information in the review screen.
user.info.statsDisplays account statistics to help confirm the production account.
video.listLists videos available to the authorized account for source selection.
video.uploadTransfers a user-selected video to TikTok as a draft.

What a reviewer can verify

The public information on this page is available without a service account. The service button opens TikTok's official authorization screen. A reviewer using an account permitted for the app can verify the same sequence shown in the submitted review video:

  1. TikTok authorization and permission review
  2. Connected profile and statistics display
  3. Recent video list and source selection
  4. Explicit confirmation before draft transfer
  5. Draft received in TikTok with no automatic public post

Data handling and user control

  • Social Connector only requests the permissions listed above.
  • It does not sell account data or use it for unrelated advertising.
  • The user can revoke the app in TikTok or use the disconnect link below.
  • Deletion requests and retention details are explained on the data deletion and privacy pages.
