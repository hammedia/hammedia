# 이벤트 데모 인물 복원 증거

- 결함 URL: `https://hammedia.co.kr/examples/seasonal-event/`
- 결함 원인: 현재 분기의 최초 데모 커밋 `0608f3e`가 기존 생성형 모델 자산 대신 CSS 달만 사용했다. 깨진 이미지나 최근 삭제가 아니라 데모 생성 당시 누락이다.
- 복원 자산: 기존 생성 원본 `hero_model_05.png`를 변경하지 않고 1240×1661 WebP(82,422B)로 파생했다. 실제 인물 사진이 아니라 기존 제작 기록에 명시된 생성형 모델이다.
- PC: `desktop-full.png` — 1280px 브라우저 전체 화면, 얼굴·본문 표시.
- 모바일: `mobile-390-full.png` — 390px 브라우저 전체 화면, 얼굴·본문 표시, 문서 가로 넘침 없음.
- 미리보기: `preview-1200x630.png` — 서비스 카드와 OG 이미지에 쓰는 1200×630 화면.
- 동작: 전화 문의 체험 버튼은 외부 전송 없이 페이지 안 피드백을 표시했다.
- 서비스 연결: `/services/#event-example`에서 새 `preview.png`가 natural 1200×630으로 로드됐다.
- 독립 대조: 공개 데모는 이미지 0·CSS 달만 표시하고 새 `hero-model.webp`는 아직 404다. 로컬은 이미지 1·complete=true·natural 1240×1661·자산 HTTP 200이다.
- 상태: 로컬 복원 증거다. push·배포·공개 라이브 반영·고객 수락을 뜻하지 않는다.
